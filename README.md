# PK FITZONE – By Prasanna Karhale

A responsive gym and nutrition store demo.

## Customer features
- Horizontal swipe/scroll shelves for categories and products on the home page.
- Tap/click any product card to open its details, category, price and information panel.
- Search, category filter and price sorting.
- Cart and WhatsApp order enquiry (no online payment).

## Admin demo
- Open `index.html#admin`.
- Demo password: `fitzone123`.
- Set the business WhatsApp number in Admin Settings.
- Purchase cost and fixed margin are admin-only in this browser demo.
- Selling price is calculated as purchase cost + margin.
- Daily, monthly and product-wise reports are based on sales manually recorded in the Admin Panel.

## Important
- Product prices, costs and margins are illustrative demo values. Replace them with supplier-confirmed values before publishing.
- Product descriptions are general category-level information. Confirm actual brand, ingredients, size/weight, stock, expiry/warranty and manufacturer instructions for each SKU before sale.
- This is a front-end demo using browser localStorage. Admin password and data are not secure or shared between devices. A real multi-user store requires a secure backend, database and authentication.
