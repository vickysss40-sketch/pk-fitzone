PK FITZONE — Static Gym Shopping Store

DEPLOY:
1. Upload index.html to the root of your GitHub repository (pk-fitzone).
2. Commit the change to the main branch.
3. In Render, open the pk-fitzone Static Site service.
4. Confirm Publish Directory is "." and Build Command is blank.
5. Trigger a manual deploy or wait for auto-deploy.

FEATURES:
- Responsive product catalogue
- Search and category filters
- Cart with quantity controls (saved in browser local storage)
- Demo order enquiry summary

IMPORTANT:
This is a front-end demo. It does not process real payments, store orders on a server,
manage inventory, or send orders to the store owner. Those require a backend/payment
integration. Product names, descriptions and prices are sample content; update them
before accepting customers.
